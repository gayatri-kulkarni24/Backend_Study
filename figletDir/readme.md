# Figlet Text Banner Generator 🎨

This project is a sub-module of the **Backend_Study** repository. It demonstrates how to use the third-party `figlet` package in Node.js to convert ordinary text string inputs into stylized, text-based ASCII art banners inside the terminal console.

---

## Features
- Integrates the `figlet` npm dependency.
- Asynchronously processes text strings into custom typography layout formats.
- Logs stylized signature layouts cleanly into the standard server output pipeline.

## Installation & Setup

Follow these quick commands to spin up the package locally on your machine:

1. Navigate to the project directory:
   ```bash
   cd figletDir
   ```

2. Download and rebuild project package dependencies:
   ```bash
   npm install
   ```

3. Execute the server script:
   ```bash
   node index.js
   ```
